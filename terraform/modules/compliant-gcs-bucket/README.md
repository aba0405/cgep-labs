The module enforces key security and compliance safeguards: **SC-12** (Cryptographic Key Establishment and Management) and **SC-13** (Cryptographic Protection) through automated 90-day Cloud KMS key rotation and customer-managed AES-256 encryption; **SC-28** (Protection of Information at Rest) via default KMS bucket encryption; **AU-11** (Audit Record Retention) and data immutability through a mandatory 30-day retention policy and object versioning; **CM-6** (Configuration Settings) by validating required labeling schemas and enforcing public access prevention; and **AC-3** (Access Enforcement) by strictly mandating uniform bucket-level access control.
