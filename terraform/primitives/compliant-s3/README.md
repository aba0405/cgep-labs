This Terraform module provisions a single compliant Amazon S3 bucket and enforces key security and compliance controls aligned with NIST SP 800-53, including **SC-28** for data-at-rest encryption, **AU-3** and **AU-6** for audit logging and event review, **CM-6** for secure configuration and required tagging, and **AC-3** for access enforcement and public-access blocking. The module provides a repeatable, auditable foundation for deploying S3 resources with security controls enforced through infrastructure as code.
